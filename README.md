# 🧮 Funções e Retorno de Valores em Python

Projeto desenvolvido em Python para praticar a criação de funções, o retorno de valores e a realização de operações matemáticas.

## 📖 Sobre

O objetivo deste exercício é compreender como criar uma função que recebe parâmetros, realiza uma operação matemática e retorna um resultado que pode ser utilizado em outros cálculos.

## ✨ Funcionalidades

* ✖️ Multiplicação de dois números.
* 📤 Retorno do resultado utilizando `return`.
* ➕ Adição de um valor ao resultado retornado.
* 🖥️ Exibição do resultado final no terminal.

## 💻 Código

```python
def calcular(a, b):
    return a * b

valor = calcular(4, 5)

resultado = valor + 10

print(resultado)
```

## 📌 Exemplo de execução

```text
30
```

## 🧠 Conceitos praticados

* **Funções (`def`):** criação de blocos de código reutilizáveis.
* **Parâmetros (`a`, `b`):** valores recebidos pela função.
* **`return`:** devolve o resultado da multiplicação.
* **Variáveis:** armazenamento dos resultados intermediários.
* **Operadores matemáticos:** multiplicação (`*`) e adição (`+`).
* **`print()`:** exibição do resultado final.

## ⚙️ Como funciona

1. A função `calcular(a, b)` recebe dois números.
2. O comando `return a * b` retorna o resultado de `4 * 5`, que é `20`.
3. A variável `valor` recebe esse resultado.
4. A variável `resultado` soma `10` ao valor retornado, obtendo `30`.
5. O comando `print(resultado)` exibe o resultado no terminal.
